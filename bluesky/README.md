# Bluesky publisher

Use the root `kulturbytes-social bluesky` command. Configure `BLUESKY_HANDLE`
and a **Bluesky App Password** in `BLUESKY_APP_PASSWORD`. The optional
`BLUESKY_SERVICE_URL` selects the account's HTTPS PDS (default `https://bsky.social`).
See the root README for configuration, dry runs, and recovery.
